# Devices

These scripts are called during SIGpi installation as well as from the **SIGpi device (remove|purge|install|build) package <DEVICE>** script for managing devices

SIGpi project does its utmost to ensure the most recent stable releases for devices are available for installation and maintained in the **debs** directory.

When running **SIGpi device package <DEVICE>** the resulting debian packages are stored in the **debs** directory.

# Debian Packages

The SIGpi project does its utmost to ensure the most recent stable releases are available for installation and maintained in this directory.

When choosing install from the **SIGpi menu** application or running **SIGpi install <PACKAGE>** at the command line the Debian packages in this directory are used. Some packages may add a repor to get the lates package from there.

When running **SIGpi package <PACKAGE>** or **SIGpi device package <DEVICE>** the resulting debian packages are stored here.
